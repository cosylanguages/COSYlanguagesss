### Deployment Workflow

- **Hosting Platform:** GitHub Pages (`https://cosylanguages.github.io/COSYlanguages/`).

- **Deployment Trigger:** Automated push to the `main` branch via GitHub Actions workflow (`.github/workflows/deploy.yml`).

- **Build Step:** Runs `node scripts/build-blog.js` during deployment to compile blog JSON posts and generate `blog/posts.json`.

- **Environment Injection:** Injects public Supabase URL (`window.COSY_SUPABASE_URL`) and anon key (`window.COSY_SUPABASE_ANON_KEY`) into `js/config.js` at deploy time.

- **Artifact Upload:** Uploads root directory `.` as static pages artifact (`actions/upload-pages-artifact@v3`).


### Access Control Mechanism

- **Server-Side Access Control:** **None.** All files in the repository (HTML pages, JSON data, course specifications, lesson plans, templates, practice datasets) are served as raw static files over public HTTP.

- **Client-Side Auth (Supabase SSO):** `js/core/auth-sso.js` handles client-side authentication token restoration from URL hash fragments (`#access_token=...`) and decorates outbound links across COSY repositories with auth tokens.

- **Client-Side Role Gate:** `js/core/cms-editor.js` gates the on-page visual editor for `admin`, `founder`, and `owner` roles client-side.

- **Paid Content Exposure:** Courses (`courses/`), lesson plans (`templates/`), and premium events (`apps/premium-events/`) are completely public and accessible to any unauthenticated web browser.
