# Skyeng vs COSYlanguages — Competitive Analysis

**Scope:** Skyeng's lessons, courses, curriculum, roadmaps, methodology, platform, and pricing — compared against COSYlanguages' own courses (`data/courses/courses.json`), curricula (`curriculum/en/*`), and ecosystem (`COSYtools`, `COSYgames`, `COSYevents`).

**Purpose:** identify what COSY can learn from Skyeng, what COSY already does better or differently, and concrete gap-filling actions that feed back into the curriculum and ecosystem.

**Sources:** [Skyeng programs page](https://skyeng.ru/programs/), [Skyeng adults](https://skyeng.ru/adults/), [Engblog independent review](https://engblog.ru/skyeng-review), [Vimbox academic paper](https://ceur-ws.org/Vol-2562/paper-03.pdf).

## Headline contrast

Skyeng is a **teacher marketplace with a proprietary platform** (live 1-on-1 and group lessons, AI-personalised materials, a 24/7 speaking bot, and a level-up guarantee). COSYlanguages is an **open content + ecosystem** (a GitHub monorepo of CEFR-graded curricula, interactive manuals, drills, games, and community events) built around a monolingual, CELTA-staged, machine-readable pedagogy. They overlap on curriculum coverage (A1–C2) but differ fundamentally on delivery model.
